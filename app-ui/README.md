# FCHIP app-ui

Visual directory of **proposed** FCHIP screens from `.cursor/app-write-up.mdc` and `app-flows/`.
Not generated from `frontend/` code.

**50 screens** × mobile / tablet / desktop = **150 mockups**.

Slogan: **Your health, our mission.**
